Una web sencilla

Esta web no incluye formularios de registro, publicidad, analítica, cookies propias ni almacenamiento de datos en tu navegador. No necesitas crear una cuenta para consultar los planes.

Las fuentes y las imágenes se sirven desde el mismo sitio. Al pulsar «Copiar plan», tu navegador puede pedir permiso para escribir en el portapapeles. Solo se copia el texto del plan seleccionado; no leemos tu portapapeles.

Enlaces y alojamiento

Los enlaces a mapas abren Google Maps. Al visitar un servicio externo, se aplican sus propias condiciones y políticas de privacidad. El proveedor de alojamiento puede procesar información técnica de las peticiones, como la dirección IP, para servir la web. Consulta la política de privacidad de Vercel, el proveedor de alojamiento de esta web.

Sobre los planes

Happy Run está preparando su lanzamiento. Los planes identificados como propuestos no son convocatorias confirmadas. Espera a que el club publique la información definitiva antes de acudir.

Fotografía e identidad

La imagen principal se ha generado con inteligencia artificial como imagen conceptual para Happy Run. No muestra a miembros reales del club ni documenta un evento celebrado. La identidad gráfica y el contenido se han creado para este proyecto.

La tipografía Bricolage Grotesque, de los autores del proyecto Bricolage Grotesque, se distribuye bajo la SIL Open Font License 1.1.

Inspiración

Este proyecto se ha inspirado en la conexión entre personas de Founders Running Club, la claridad de las sesiones de Campus Runners y el espíritu social de Midnight Runners. Happy Run es un proyecto independiente y no está afiliado a estos clubes.
